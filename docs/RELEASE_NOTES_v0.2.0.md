# SUPRA Writer v0.2.0 — First public preview

SUPRA Writer is a free, open-source browser-based word processor designed around plain-language settings and one-click document styles.

## Included
- Functional writing, basic headings, lists and tables, with DOCX, HTML, TXT and browser PDF output.
- 162 searchable font-family names, custom font import, readability controls.
- Five Quick Looks, twelve Advanced looks and up to 25 personal looks saved locally.
- Unicode irony mark `⸮` and a 30-character symbol palette.
- Downloadable self-contained HTML file that runs offline.
- GitHub Pages web editor, PWA manifest and browser-based installation option (browser dependent).

## Download and run
Download `SUPRA_Writer_v0.2_Standalone.html` from the release assets and open in Chrome or Edge. No installation or online account is needed. Alternatively use https://flandersdb-oss.github.io/SUPRA-Writer/ to edit online.

## Important limitations
This is an experimental preview rather than a feature-complete Word replacement. DOCX round-tripping is incomplete, true pagination and images are not supported, and local browser drafts are not cloud backups. Export documents frequently. Specialized font names are choices, not bundled licensed fonts.
