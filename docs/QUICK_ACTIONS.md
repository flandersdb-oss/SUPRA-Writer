# SUPRA Writer — Quick Actions

The **⚡ Quick Actions** panel reduces multi-click formatting operations to a single task-oriented command.

Press **Ctrl+K** (Cmd+K on supported systems) and type a goal. Use the arrow keys and Enter or select an option with your mouse/touch. Escape closes the panel.

One-click workflows: professional letter, academic paper, comfortable reading, ready to print, compact page, and book manuscript. They bundle existing settings; they do not alter document text. Undo last look restores your previous appearance.

Other commands jump to font/page/advanced settings, locate words, open find-and-replace, or access existing file Open/Save and Print controls.

**Limitations:** The printer-friendly workflow does not guarantee optimal page breaks or color usage. Page-count reduction is approximate. Complex Word formats, page breaks and headers still require a more advanced document engine. This interface is not an AI feature and does not require network access.
