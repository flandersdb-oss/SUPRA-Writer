# SUPRA Visual Identity — interim specification (v0.1)

- **Core glyph:** flowing S-shaped document ribbon and fountain-pen nib.
- **Geometric cues:** symmetry, nested circles, measured alignment, simplified visual mass.
- **Colors:** ink navy #0a172b, silver-white, cobalt blue, restrained gold.
- **Product use:** identical core glyph for Writer's desktop `.ico`, PWA, Android-adaptive maskable image.
- **Future suite:** design a shared SUPRA parent glyph, followed by visual variations for Writer, Sheets and Present. This first Writer design is provisional, not the final suite-wide mark.
- **Accessibility:** preserve contrast, a legible simple silhouette at 16 and 32 pixels, and label all text controls. Avoid relying on color alone.
- **License:** generated image asset is original AI-generated design, not a third-party font or logo. It is included as project art under the project's distribution terms. Reassess trademark/name clearance before broad commercialization.
- **Device packaging:** Windows uses `build/icon.ico`; browser & PWA use `icons/icon-192.png` and `icons/icon-512.png`; Android-compatible PWA masking uses `icons/icon-maskable-512.png`. Native Android APK is future work.
