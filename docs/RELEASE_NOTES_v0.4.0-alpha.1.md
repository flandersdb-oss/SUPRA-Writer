# SUPRA Writer v0.4.0-alpha.1 — Windows Alpha

## What's in this alpha

- Actual 64-bit Windows setup and portable executables, generated by the GitHub Windows CI runner.
- Shared temporary SUPRA Writer icon system: Windows `.ico`, browser/PWA icons, Android-compatible adaptive-maskable image, and consistent app-header logo.
- Offline document editing; native Open, Save, Save As, Print, and PDF export.
- Searchable fonts, accessibility controls, one-click document looks, symbols, and Find/Replace.
- DOCX, HTML, and TXT import/export (limited Word fidelity).

## Alpha status and limitations

This is **alpha software**, not a complete Microsoft Word replacement. Complex Word formatting can change during import/export; page breaks, images, headers/footers, footnotes, comments and tracked changes remain incomplete. Do not use for irreplaceable documents without an independent backup. Test with copies.

Windows executable packaging is validated on GitHub Actions, but installation on a variety of Windows 10/11 computers, code signing, and device security checks remain outstanding. An unsigned installer may trigger Windows warnings; do not bypass security controls blindly.

## Fonts and icons

No third-party font binaries are bundled. The generated icon is temporary and will eventually be replaced by a shared SUPRA visual identity across Windows and Android apps. A maskable PWA icon does not equal an Android APK; a dedicated Android build has not been shipped.

## Quality gates

The Windows pipeline runs source syntax and desktop boundary tests before packaging. Browser regression and security workflows run separately. Successful packaging alone does not establish feature parity or device-level testing.
