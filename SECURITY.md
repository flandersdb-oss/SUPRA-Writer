# Security Policy

## Supported versions

Only the newest published SUPRA Writer build is actively evaluated for security issues. This is early experimental software, not appropriate for sensitive production documents without independent review.

## Report a vulnerability

**Do not post exploit details or private documents in a public issue.** If GitHub's **Private vulnerability reporting** is enabled, use the repository's **Security → Advisories → Report a vulnerability** option. Otherwise, open a public issue requesting a secure reporting contact **without including the vulnerability details**; a maintainer can provide a private channel.

## Security promises and limitations

- The current website is statically hosted; SUPRA Writer does not automatically send your document contents to an application server.
- A local browser draft is not an encrypted backup, secure vault, or cross-device sync system.
- Browser extensions, device malware, and downloaded files may affect privacy; use trusted software and secure devices.
- Never open untrusted or unknown Word/HTML files without considering risks.
- Dependencies and generated DOCX are covered by ongoing testing but are not guaranteed vulnerability-free.
